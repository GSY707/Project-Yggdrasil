# 可读拆分导航（2026-06-01）

本文件用于定位‘入口文件 -> 可读分片’关系，避免动态执行分片导致的阅读困难。

## 规则
- 入口文件只保留显式 `from ... import *`。
- 禁止 `exec(compile(...))` 动态拼装。
- 分片文件可直接打开阅读和修改。
