## 失败生成与处理

本轮曾提交 `Data & Privacy` 和 `Maintainer Workbench` 两个新页面生成请求，Stitch 返回 transport error。按照 Stitch MCP 的重试约束没有重复发送相同请求；项目中已有的 `Privacy Flow: Data Leaving Machine Review (V3)`、`Launcher: Diagnostics (V2)` 和 `Yggdrasil Launcher: System Diagnostics` 作为对应的已存在视觉源，相关 Web 页面仅复用其已确认的 Roots & Circuitry 结构，不把失败请求伪装成已生成 source。

## 实现映射

- Task Hub → `/tasks`；Task Detail → `/tasks/[taskId]` 与 `/tasks/[taskId]/analysis`。
- Materials → `/assets`；Application Detail → `/applications/[appId]`。
- Help & Diagnostics → `/release` 的用户支持入口及维护者状态页。
- 共享双语合同在 `apps/web/app/i18n.ts`、`locale-provider.tsx`、`language-switcher.tsx`；当前仅启用 `zh-CN` 与 `en`，新增语言只需扩展 `SUPPORTED_LOCALES` 与消息包。
