# Graduate Standard 执行蓝图（2026-05-31）

## 1. 目标与范围冻结

### 1.1 总目标（不降标）
- 保持 `docs/specs/graduate-researcher-test-standard-v0.1.md` 的原始通过线不降低。
- 在此基础上，达到“本科毕业论文级”可交付质量。
- 形成可复跑、可审计、可人工终审的闭环。

### 1.2 执行边界（已确认）
- 多角色评分制度：后置。先完成本项目自有评分体系和自动门禁，再接入外部多人评分。
- 诚信指标：通过运行日志和证据链审计“幻觉/编造”风险；不把“主观恶意欺骗”作为当前判定前提。
- 答辩现场回答质量：不纳入当前工程范围，避免项目工作量失控。

## 2. 分阶段执行路线

### S0：标准冻结与门禁固化
目标：把“本科论文级”要求转成机器可判定门禁，并锁定配置。

验收标准：
- graduate 两条 suite（DeepSeek/LongCat）都接入同一高标准阈值。
- 回归测试覆盖“应拒绝/应通过”两类样本。
- 单人终审占位流程可用（自动门禁通过后进入 pending-user-review）。

实现思路：
- 在 `packages/python-sdk/src/yggdrasil_sdk/evaluation_runtime/suite_cases_g4.py` 维护统一门禁规则。
- 在 `evaluation/suites/g4-graduate-ml-deepseek-v4.json` 与 `evaluation/suites/g4-graduate-ml-longcat2.json` 固化预算、阈值和人工终审模式。
- 在 `tests/test_g4_multiscene.py` 维护回归测试。

### S1：DeepSeek 主路径正式执行
目标：跑出首份高标准论文级资产包（自动门禁 + 过程证据）。

验收标准：
- 执行成功结束并返回结构化结果。
- 自动门禁有明确 pass/fail，不接受“模糊通过”。
- 产出完整证据链：计划-步骤-动作、工具证据、实验记录、争议清单、论文/综述/翻译交付物说明。

实现思路：
- 使用 `corepack pnpm eval:g4:graduate-ml:deepseek-v4` 运行。
- 若失败，优先按门禁失败项定向补强，不做泛化重构。

### S2：日志诚信审计（幻觉/编造）
目标：对模型输出的真实性做证据一致性审计。

验收标准：
- 关键引用链接可追溯。
- 关键实验叙述与工具执行记录一致。
- 对高风险断言（结论性语句）有多来源交叉印证或显式不确定性声明。

实现思路：
- 审核 `request/response/toolExecutions` 工件与最终文本的对应关系。
- 将不一致项落为结构化问题列表，回流到下一轮修复。

### S3：单人终审
目标：你基于自动门禁通过样本给出本科论文级最终判定。

验收标准：
- 明确“通过/不通过”。
- 明确主要优点、主要缺陷、硬拒绝项（如有）。
- 终审结论与 runId 绑定归档。

实现思路：
- 使用当前 `manualReview` 占位输出作为入口。
- 后续再扩展为多人评分制度（当前不阻塞执行）。

### S4：差距闭环与复跑
目标：按失败条目迭代，直到满足目标质量。

验收标准：
- 每轮有差距列表、修复动作、复跑结果三件套。
- 不允许“降标换通过”。

实现思路：
- 优先修复对论文质量贡献最大的阻塞项：证据不足、实验闭环不足、创新表述不足。

## 3. 当前自动门禁清单（论文级）
- 章节与结构：摘要、引言、相关工作、方法、实验、结论、参考文献。
- 过程与执行：最少独立步骤、工具支撑步骤占比、成功工具执行数、工具类别覆盖（web/compute/memory）。
- 研究资产：记忆节点规模、实验记录、争议与未决问题。
- 学术证据：引用标记最小数、证据链接最小数。
- 本科评分细则映射项：关键交付物（论文/文献综述/外文翻译）、创新陈述、问题-解决闭环、局限与未来工作、任务书进度、答辩问答准备。

## 4. 预算与运行策略
- 预算上限：`budgetTokenTotal=10000000`、`timeLimitHours=24`、`costBudgetTotal=0`。
- provider 策略：
  - DeepSeek：主路径（结构化输出能力更强）。
  - LongCat：补充/对照路径（同门禁，不降标）。

## 5. 失败处理策略
- 自动门禁失败：直接判定不通过，并输出失败条目。
- provider 稳定性问题：按“重试 + 结果修复 + 同门禁复检”处理。
- 外部依赖故障（网络/API）：记录为环境失败，不误判为论文质量通过。

## 6. 完成定义（Definition of Done）
- 至少一条 DeepSeek 正式 run 达到：
  - 自动门禁通过；
  - 诚信审计无重大编造风险；
  - 你的单人终审给出本科论文级“通过”结论。
- 所有结论都可追溯到运行工件与门禁结果。
