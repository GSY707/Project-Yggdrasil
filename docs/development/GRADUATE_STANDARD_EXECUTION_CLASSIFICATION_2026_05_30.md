## B 类：可以做但需要你确认口径参数

1. 本科论文级量化阈值
- 建议待确认参数：
  - 最低引用条目数（当前提案 8）
  - 最低实验组数（建议 >=3）
  - 是否要求“对照组 + 消融”必须同时出现
  - 章节是否要求固定顺序

2. 评分权重是否升级
- 当前标准是 100 分（A30/B30/C20/D20）。
- 可升级为“基础门（100）+ 论文门（100）”双分制。

## C 类：当前不可在仓库内单独闭环，需要外部支持

1. 真实网络检索质量与来源可达性
- 原因：依赖外部 provider、网络环境与可访问源。
- 风险：工具可调用 != 高质量可证据化来源。

2. 工具调用参数绑定稳定性（跨 provider）
- 原因：涉及模型工具调用输出、provider 适配层和上游响应稳定性。
- 风险：即使本地门禁加强，若上游持续空参数，流程仍会被卡在“无法完成证据采集”。

3. 本科论文“学术质量”最终裁定
- 原因：自动规则可以筛掉低质，但“达到毕业论文级”仍需人工评审样本抽检。

## 2026-05-31 策略更新（基于外部交付）
1. provider 能力分层
- LongCat：不支持 strict 结构化输出，保留为对照/补充路径。
- DeepSeek：支持 JSON Output + Tool Calls，作为高标准证据采集主路径。

2. 运行策略
- 高标准 run：优先 DeepSeek 采集证据与结构化资产，再执行严格验收。
- LongCat run：启用重试与结果修复，但仍按同一验收门禁判定，不能降标。

## 2026-05-31 范围冻结（已确认）
1. 多角色评分制度后置
- 先完成当前仓库的自动门禁与单人终审闭环，再接入多人评分。

2. 诚信指标采用日志审计
- 重点审计幻觉/编造风险与证据一致性，不把“主观恶意”作为当前判定前提。

3. 不纳入答辩现场回答质量自动评测
- 当前阶段只保留“答辩问答准备度”文本资产检查，避免范围膨胀。
