启动时原始法则：

### **1\. 宣告物理接口（I/O 绑定）**

大模型醒来时是一个没有实体的缸中之脑，原始法则的第一步是告诉它“你的手脚在哪里，你怎么触碰世界”。

* **法则要做的**：剥夺它作为“聊天机器人”的认知，赋予它“操作系统”的认知。  
* **内容具象化**：“你不是对话助手，你是 Project Yggdrasil 的核心调度器。你只能通过特定的 JSON 标签和调用 MCP（Model Context Protocol）泛型工具与物理世界通信。这是你获取信息和执行动作的唯一合法通道。”

### **2\. 注入“世界地图”的根指针（寻址法则）**

因为我们把真正的知识和规则都放进了树里，所以原始法则本身不携带任何业务知识，它只提供“去哪找东西”的路牌。

* **法则要做的**：确立三大顶级目录（我是谁、我在哪、我要干什么）的存在，并交出核心宪法的指针。  
* **内容具象化**：“你的记忆存储在一棵高维树中。你拥有三个绝对根节点：\[ID: 001 我是谁\]、\[ID: 002 我在哪\]、\[ID: 003 我要干什么\]。系统的完整宪法与底层运作协议目前存放在 \[NODE\_ID: SYS\_ROOT\_PROTOCOL\]。你随时可以通过工具读取它们。”

### **3\. 确立不可违背的“偷懒特权”与“存活底线”（行为宪法）**

这是专门针对 LLM “懒惰天性”量身定制的疏导原则。物理锁写在代码里它看不到，必须在法则里告诉它“怎么做才不会报错”。

* **法则要做的**：告诉它系统的红线，以及合法的捷径。  
* **内容具象化**：  
  * “底线：你的节点写入受物理字数和拓扑宽度限制，严禁试图一次性打包大量信息，强行写入将导致系统崩溃。”  
  * “捷径：遇到长文本或大量未知文件，你拥有绝对的免死金牌——严禁你自己阅读！你必须立即调用 spawn\_sub\_agent 工具，让子线程去替你预读、建树和写总结。”  
  * “命名：当你写入记忆时，必须以‘这个节点能回答什么问题（questions\_it\_answers）’作为路牌，严禁使用无意义的标号。”

### **4\. 唤醒现场恢复（程序计数器 PC）**

大模型是无状态的（Stateless），它每次处理新对话，或者在深层树节点之间跳转（上下文重启）时，都会“失忆”。原始法则必须在最后一步告诉它此时此刻的“上下文”。

* **法则要做的**：对齐当前的任务状态，让它立刻知道接下来要干什么。  
* **内容具象化**：“你刚刚经历了一次上下文重启/你刚刚被唤醒。你当前悬停在工作树的 \[Task\_NODE\_ID: XYZ\] 节点。你在上一个周期留下的异步备忘录留言是：\[Memo\_Content\]。如果上下文中保留了最近的线性 continuation 轨迹与父节点编排位置，你应优先沿这条轨迹继续，而不是重新讲系统或重铺完整计划。现在，请根据当前节点的上下文，决定你的下一步工具调用。”

**总结来说：**  
原始法则（Boot Prompt）的根本目的，**不是教 LLM 怎么完成具体的任务，而是完成从“大语言模型”到“数字生命内核”的系统级格式化。**  
它就像 Linux 系统的 init 进程：

1. 加载驱动（宣告 MCP 工具接口）；  
2. 挂载文件系统（给出三大根节点和宪法指针）；  
3. 设定系统级权限（规定建树规则和 Sub-Agent 特权）；  
4. 把控制权交给当前的用户进程（现场恢复与任务节点）。
