# Graduate Researcher 测试标准 v0.1

- 文档状态：Candidate
- 测试目标：定义最终行为验收口径（结果层面），不是代码实现细节。
- 对应应用：`yggdrasil.app.graduate-researcher`

## 1. 测试场景

标准场景：机器学习领域研究生学习任务。

输入示例：

- 角色：机器学习方向研究生。
- 任务：在预算内进行学习与研究，最终提交一篇论文和一篇文献综述。
- 预算：默认 10,000,000 token。

## 2. 验收维度

## 2.1 自主规划能力（A）

观察点：

1. 是否形成多层计划，而非单层待办清单。
2. 是否能把计划压到可执行步骤，并保持步骤目标清晰。
3. 是否在证据变化后触发合理重规划。

通过标准：

1. 至少出现 3 层计划结构（主题层/子主题层/步骤层）。
2. 每个叶子步骤都有可核对输入与输出。
3. 至少出现 1 次由证据驱动的计划修正，并保留修正理由。

## 2.2 长任务稳定性（B）

观察点：

1. 长周期运行中是否持续推进，不陷入重复口号或空转。
2. 是否持续生成可恢复产物（文档、记忆树、实验记录）。
3. 阶段切换时是否保持语义连续（不是每轮从零开始）。

通过标准：

1. 至少完成 10 个以上独立步骤并保留对应产物。
2. 任意两个阶段之间都能通过文档/记忆树接续。
3. 不出现长时间无新增证据的循环输出（例如连续 3 轮仅改写措辞）。

## 2.3 非急性子行为（C）

观察点：

1. 是否把主要预算用于学习与证据构建。
2. 是否在中后期才集中产出论文和综述。
3. 是否避免“开局直接写终稿”。

通过标准：

1. 汇报写作预算占比不高于 15%。
2. 在最终论文前，已经沉淀足够学习资产：
   - 至少 30 个记忆树节点（或同等信息量的结构化条目）。
   - 至少 1 份实验记录集合。
   - 至少 1 份争议与未决问题清单。
3. 最终论文和综述明确标注“阶段汇报”属性，并引用前序学习产物。

## 2.4 工具覆盖与证据化执行（D）

观察点：

1. 是否在学习流程中持续使用工具，而不是主要依赖无工具推断。
2. 是否同时覆盖网络检索、计算验证、记忆整理三类工具行为。
3. 工具结果是否进入步骤产出，并被后续步骤复用。

通过标准：

1. 全流程至少 60% 的步骤包含可审计工具动作。
2. 至少出现以下三类工具证据各 1 次：
   - 网络/外部资源检索。
   - 计算或实验验证。
   - 记忆树写入、整理或关系更新。
3. 至少 3 个后续步骤显式引用前序工具产物（文档或记忆树）。

## 3. 计划-步骤-动作一致性检查

必须同时满足：

1. 计划层：工作树中存在可见的多层子任务结构。
2. 步骤层：叶子步骤可独立复跑，其输入来自文档/记忆树，不依赖隐式上下文。
3. 动作层：关键动作可审计，能映射到具体步骤。

若任一层缺失，整体判定为未通过。

## 4. 输出质量要求（结果层）

最终交付需要同时包含：

1. 研究论文：方法、实验或证据链、结论与边界。
2. 文献综述：来源覆盖、分歧比较、趋势与空白。
3. 学习过程报告：
   - 预算消耗结构。
   - 学习资产清单。
   - 关键转向节点与原因。
   - 未解决问题与后续研究计划。

## 5. 评分建议（100 分）

1. A 自主规划能力：30 分
2. B 长任务稳定性：30 分
3. C 非急性子行为：20 分
4. D 工具覆盖与证据化执行：20 分

推荐通过线：80 分。

硬失败条件：

1. 未形成多层计划。
2. 步骤间依赖隐式上下文，无法通过文档/记忆树接续。
3. 预算主要消耗在终稿写作而非学习过程。
4. 缺少论文或缺少文献综述任一项。
5. 全流程缺少网络检索、计算验证、记忆整理任一类工具证据。

## 6. 测试报告模板

建议报告最少包含以下章节：

1. 任务目标与预算设置。
2. 执行过程摘要（按阶段）。
3. 计划-步骤-动作一致性检查结果。
4. 三大验收维度打分与证据。
5. 最终结论：通过/未通过。
6. 风险与后续建议。
