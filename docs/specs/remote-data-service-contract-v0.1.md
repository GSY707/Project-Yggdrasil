# 官方远端数据服务契约 v0.1

状态：计划中，未上线。

本文只冻结上线前必须满足的产品与数据边界。当前本地产品模式、完整 Docker Compose 产品栈和 Windows 桌面封装预览都不会自动把数据上传到 Project Yggdrasil 官方服务。

## 入口条件

官方远端数据服务必须同时满足以下条件后才能标为可用：

- 用户显式登录官方账号。
- 用户显式选择远端工作区。
- 用户显式打开同步开关。
- Web 工作台、CLI 和桌面封装都能展示当前远端连接状态。
- 本地数据治理页能区分本地删除、远端删除请求、远端删除证明三种状态。

## 最小远端对象

远端服务最少需要这些对象：

- `tenant`：组织或个人租户。
- `user`：账号主体。
- `workspace`：远端工作区。
- `device`：本机设备登记。
- `sync_job`：一次本地到远端或远端到本地的同步任务。
- `remote_snapshot`：远端备份快照。
- `delete_request`：远端删除请求。
- `delete_certificate`：删除证明。
- `audit_event`：不可篡改的审计事件。

## 数据分类

远端写入前必须按以下分类显示并记录：

- 任务目标、任务正文、运行状态。
- 导入素材、素材摘要、派生节点和 embeddings。
- Prompt 编译产物、模型请求、模型响应。
- 本地观测数据、Langfuse / OTel 远端观测引用。
- 备份快照和恢复记录。
- 删除请求、删除结果和保留期例外。

## 删除契约

远端删除不能复用本地 hard-delete API 的语义。它必须是一个异步请求：

1. 用户提交 `delete_request`，明确 scope、原因和确认文本。
2. 服务生成影响预览，列出将删除、将保留、无法删除的数据。
3. 用户二次确认。
4. 服务进入执行状态，并记录每个远端存储面的处理结果。
5. 服务生成 `delete_certificate`，包含请求 ID、执行时间、保留例外和审计引用。

未实现 `delete_certificate` 前，远端删除不得在 UI 中标为完成。

## 备份与恢复契约

远端备份必须支持：

- 手动创建快照。
- 周期性快照策略。
- 快照加密状态。
- 恢复演练记录。
- 版本兼容检查。
- 回滚失败后的保护性快照。

未完成恢复演练前，远端备份不得宣传为正式灾备能力。

## 当前实现边界

当前仓库已实现：

- 本地数据治理 manifest。
- 本地 task 级 dry-run 和 hard-delete。
- 本地审计表 `data_governance_operations`。
- 产品 Compose 本地 backup / restore / upgrade / rollback。

当前仓库未实现：

- 官方账号。
- 远端工作区。
- 远端同步。
- 远端备份库。
- 远端删除请求。
- 删除证明。
- 远端数据加密和保留期策略。
