# 记忆检索

> [!IMPORTANT]
> 本文是 Agent 早期概念来源。当前能力、记忆、在线身份稳定与离线进化的唯一哲学入口为[世界树计划完整设计哲学](../../../architecture/design-philosophy-and-cognitive-principles.md)。

- 读取流程：从根节点开始，通过父子关系和关联关系读取大量节点。
- 并发读取：LLM 可以同时要求多个节点的内容，快速从记忆中读取所需的内容。

# 记忆活跃度
- 记忆持续参数 k，从 0（不变的记忆）到 1（每次被调用都建议修改的记忆），决定LLM修改记忆节点内容的积极度。
- 记忆浮动，将经常使用的记忆在树中上浮，不常用的记忆下降并生成父节点

# 自我进化
- 感知项目缺陷：本项目可能存在缺陷，如果在使用中暴露问题，Agent需要主动发现缺陷，并修复。
- 分析项目理念：项目启动初期理念简单，考虑不深入，运行时发现可能更好的想法就及时尝试改进。
- 思考未来 Agent 的运行方式，及时更新最新的技术。
- 基于实际任务进化：本项目不一定适合所有任务，需要 Agent 自我对项目进行适应性改变。
- 通过评测性任务，评测更新的效果，分析是旧的好还是新的好，好在哪，差在哪，以及为什么好，为什么差。
- LLM 训练与微调，自己生成训练数据并微调 LLM，打造更适合项目的 LLM，或增强 LLM 能力。比如利用记忆树而不是用权重记忆知识。
