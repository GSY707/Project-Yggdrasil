# 世界树计划 · 超图推理协议 (Yggdrasil Hypergraph Reasoning Protocol)

> **版本**：v0.1
> **主题**：关联升维、符号化认知与高维逻辑涌现  
> **定位**：指导 Agent 突破线性 Token 表达限制的元认知协议

---

## 1. 关联的节点化：从“边”到“核”

在世界树系统中，关联（Relation）不仅是连接记忆节点的线条，它被视为具有独立推理价值的“节点” [cite: PRD-v0.1.md, 记忆树核心设计.md]。

* **逻辑升维**：当 Agent 将“关联原因”提取为独立对象时，系统从传统的知识图谱进化为超图（Hypergraph）架构。
* **推理重心转移**：元认知下令暂时屏蔽实体节点的代码/文本细节，转而平铺关联边的元数据（类型、权重、逻辑原因）进行推理。
* **乘法效应**：关联使得原本没有上下级关系的记忆点形成联系，这是对知识进行乘法，形成推理能力的涌现 [cite: 系统核心理念.md]。

## 2. 超图推理路径 (Hypergraph Reasoning Path)

针对复杂架构设计或深层 Bug 排查，Agent 必须执行以下协议：

1.  **实体脱敏**：停止对具体实现细节的低维读取。
2.  **关联建立**：在需要推理的范围内建立更多关联，提升关联密度。
3.  **关系平铺**：请求检索特定范围内的所有“关联边”，将它们的逻辑原因并置于上下文窗口中。
4.  **模式识别**：通过审视关系的集合，发现跨模块的结构性模式（如潜在的公共切面或循环依赖）。

## 3. 代数化认知与符号发明 (Algebraic Cognition)

为了突破 LLM 线性输出 Token 的“表达屏障”，本协议引入代数思维：

* **符号化占位符**：当产生复杂的架构直觉但难以用 Token 精确描述时，Agent 允许发明一个代数符号（如 `[Pattern_Sigma]` 或 `[Anomaly_X]`）。
* **代数演算**：后续推理不再试图解释其内部细节，而是围绕该符号的输入输出关系进行逻辑演算。这类似于数学中使用符号 $i$ 处理虚数，极大地节约了 CPU 缓存（上下文窗口）。
* **命名即掌控**：通过赋予抽象直觉以名字，元认知获得了对模糊思维片段的调度权。

## 4. 思维蒸馏与奥卡姆剃刀

* **递归思考**：利用无限算力对任何事情进行递归思考 [cite: Agent行为模式建议组.md]。
* **蒸馏法则**：在发散性思考后，元认知必须介入，重新审视问题并评估各个想法的贡献，删除或简化意义不大的部分 [cite: Agent行为模式建议组.md]。
* **剃刀法则**：如果围绕某个代数符号的推演连续 3 次未能产生实质性的代码变动或任务推进，该符号将被判定为“认知噪音”并被主动遗忘，以实现信息熵的自我净化 [cite: 记忆树其他设计.md, 系统核心理念.md]。
