## 1. 出口判定

Gate 4 以四条正式出口标准判定：

1. 官方 coding / research / writing 三个场景都要有正式 prompt profile、seed template 与 few-shot 合同，不再依赖漂浮资产。
2. few-shot 必须真正进入 runtime messages、prompt compile artifact 与 Prompt 控制面，而不是只停留在 YAML 字段。
3. 必须有覆盖快任务合同、跨会话恢复合同、pause/resume 恢复与场景切换隔离的正式离线 suite。
4. 必须有标准化 live provider matrix，能够在付费 provider 开关开启时复跑官方三场景，并保留统一的延迟、成本与 takeover 指标口径。

本次闭环满足以上四条：

1. 官方三场景现在统一由 scene module 持有正式 seed 与 few-shot 资产，应用目录中未接线的本地 `scenes/` 已清理。
2. `CompiledPrompt`、runtime messages、prompt compile artifacts 与 Prompt 控制面都已经显式暴露 `fewShotRefs`。
3. `evalsuite_g4_multiscene` 已完成 10/10 通过，覆盖 `g4.scene_prompt_contract`、`g4.scene_resume_contract`、`g4.scene_runtime_recovery` 与 `g4.scene_switch_isolation`。
4. `evalsuite_g4_provider_matrix` 已完成 6/6 通过，覆盖 `deepseek_direct / deepseek-v4-pro` 与 `longcat / LongCat-Flash-Lite` 的三场景 live 验证。

## 2. Gate 4 正式增量

### 2.1 few-shot 执行链闭环

- PromptCompiler 新增正式 few-shot 资产发现、合并与解析逻辑。
- few-shot 现在按 `profile.fewShotRefs` + `seedTemplate.fewShotRefs` 的顺序去重合并，并注入到 system message 与最终 user message 之间。
- `CompiledPrompt`、compile-preview 响应与 prompt compile artifact 全部保留 `fewShotRefs`。

### 2.2 官方场景资产收口

- `scene-coding-new-project`、`scene-research-deep`、`scene-writing-epic` 三个官方 scene module 现在都自带正式 few-shot 资产。
- 官方应用的 seed 来源统一收口到 `sceneModules`，删除了 `applications/coding-greenfield`、`applications/deep-research`、`applications/epic-writing` 下未接线的本地 `scenes/generic-default.yaml`。

### 2.3 多场景评测与 provider matrix

- 新增 `g4.scene_prompt_contract`、`g4.scene_resume_contract`、`g4.scene_runtime_recovery`、`g4.scene_switch_isolation`、`g4.live_provider_matrix` 五类 G4 scenario handler。
- 新增 `evaluation/suites/g4-multiscene.json` 与 `evaluation/suites/g4-provider-matrix.json`。
- `scorer.py` 现在会聚合 `providerMatrix` 与 `providerSummary`，统一输出 provider 级统计。

### 2.4 Prompt 控制面与发布门禁

- Prompt 控制面页面现在显式展示 profile / seed / compiled prompt 的 `fewShotRefs`，不再只显示 profile 与 seed id。
- 根 `package.json` 新增 `corepack pnpm eval:g4:multiscene` 与 `corepack pnpm eval:g4:provider-matrix`。
- `release:check` 已纳入 `eval:g4:multiscene`。
- `release-check` workflow 新增手动 `run_g4_provider_matrix` 入口，并在该 job 中显式设置 `YGGDRASIL_ALLOW_PAID_MODELS=1`。

### 2.5 live 验证期间形成的正式修复

- G4 live matrix 不再继承 bootstrap 中固定的 `tokenBudgetTotal=1200`；live case 现在走“token 无上限、仅保留 `costBudgetTotal`”的正式预算策略，避免 post-invocation budget false negative。
- G4 live matrix 现在会把 start payload 中的 `takeoverProtocol.metrics` 合并进 scorecard 口径，正式输出 `planQualityScore0_100`、`reworkCount` 与 `reworkRate`。
