# 显示subagent和隐示subagent设计

subagent永远是给主agent用的。这个项目的目的是打造超级个体。显示subagent类似协作单元，由主agent布置任务，主agent明确知道自己启动了一个subagent。隐示subagent更接近功能单元，比如主agent想要阅读一批文档/查一批资料，它会启动一个工具”把这些东西导入记忆树“，主agent不关心导入的结果，只关心过程，所以主Agent不需要知道这里有没有用到subagent。再比如启动上下文清理，主Agent只按下按钮，并不需要布置一个清理上下文的任务。

# 服务真实用户

原则：“浪费”一部分 token，让用户不需要学习提示词工程。绝不交付半成品。

某一方向：创意开发应用：同时默认用户知识较少且只提供创意/目标，世界树需要完全接管项目。不要让用户决定技术细节，用户只决定效果。

最终目标：通用世界树Agent+一个初始原则+用户任务->完美完成任务。中间只和用户对齐需求。这个世界树Agent运行在服务器端，拥有自己的资源。

自我即产品：有的时候任务可能是角色扮演，或者持续的工作，比如客服，学习辅导。任务的交付目标可以是agent自身。
