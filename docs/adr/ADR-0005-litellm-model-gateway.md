# ADR-0005：采用 LiteLLM + 自定义模型路由作为模型网关

- 状态：Accepted
- 日期：2026-04-16

## 背景

项目明确需要：

- 多模型接入。
- 自动选模。
- 预算与成本控制。
- 不同任务按能力分配模型。
- 失败回退与供应商替换。

因此不能把模型调用直接散落在各个模块里。

## 决策

采用 LiteLLM 作为统一模型网关，对接不同供应商；在其之上增加自定义模型路由器，用于：

- 能力标签。
- 成本限制。
- 预算分配。
- 回退策略。
- 场景级默认模型。

## 后果

正面影响：

- 模型调用统一，便于审计与替换。
- 成本与质量数据可以集中沉淀。

负面影响：

- 需要维护额外的路由策略层。
- 某些供应商特性需要做适配降级。

## 备选方案

- 各模块各自直连模型供应商。
  - 放弃，原因是预算、审计与路由无法统一治理。
