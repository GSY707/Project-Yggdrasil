# ADR-0009：采用 Langfuse + OpenTelemetry 的观测与评测体系

- 状态：Accepted
- 日期：2026-04-16

## 背景

世界树计划的优化对象不是单一 API，而是包含检索、写入、压缩、选模、工作流恢复、模块协作的完整系统。没有统一观测和评测，就无法知道哪一步造成退化。

## 决策

采用以下组合：

- Langfuse：LLM 调用追踪、提示词版本、成本分析。
- OpenTelemetry：请求链路、跨服务追踪、指标埋点。
- Grafana + Loki：日志聚合与可视化。
- pytest + 基准任务集：自动化回归评测。

## 后果

正面影响：

- 能够回答“为什么这次任务失败”以及“为什么这次优化没有收益”。
- 可以建立版本回归门禁。

负面影响：

- 需要额外维护评测数据集与追踪字段规范。
- 观测埋点不规范时，会产生噪声数据。

## 备选方案

- 仅保留应用日志。
  - 放弃，原因是无法支撑复杂任务链路的定位与回归。
