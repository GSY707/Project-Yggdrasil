# ADR-0007：采用 NATS JetStream + Outbox 事件机制

- 状态：Accepted
- 日期：2026-04-16

## 背景

模块化系统需要可靠的异步通信机制，用于：

- 异步写入。
- 建树与整理触发。
- 模块事件订阅。
- 审计分发。
- 评测任务触发。

如果直接在事务内同步调用下游模块，系统会迅速耦合并失去隔离性。

## 决策

采用以下模式：

- 同步查询与命令通过稳定 API 完成。
- 异步事件通过 NATS JetStream 分发。
- 关键状态变更采用 outbox pattern，先在数据库中落事件，再由发布器可靠投递。

## 后果

正面影响：

- 降低模块间直接耦合。
- 事件可以重放、追踪与补偿。
- 异步流程更适合演化。

负面影响：

- 系统调试复杂度上升。
- 需要幂等消费与死信处理策略。

## 备选方案

- 全部通过 HTTP 同步调用。
  - 放弃，原因是无法优雅处理异步链路与可靠重试。
- 直接使用数据库轮询作为唯一机制。
  - 放弃，原因是可扩展性和实时性不足。
