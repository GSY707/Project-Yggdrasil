# ADR-0008：采用分阶段权限系统演进路线

- 状态：Accepted
- 日期：2026-04-16

## 背景

系统长期目标包括共享记忆空间、分支空间、只读挂载、写时复制与 PR 审核，因此权限系统必须演进。但第一版若直接做完整复杂权限，会显著拖慢交付。

## 决策

采用分阶段方案：

- 第一版认证：Authentik + OIDC。
- 第一版鉴权：以 PostgreSQL ACL 与审计日志为主。
- 后续高级鉴权：逐步引入 OpenFGA。
- 数据面隔离：演进到 PostgreSQL RLS。

## 后果

正面影响：

- 第一版可以快速交付基础安全能力。
- 保留未来共享记忆空间的演进路径。

负面影响：

- 第一版与高级权限模型之间需要迁移设计。
- 审计模型必须从一开始保持稳定。

## 备选方案

- 一开始做完整 OpenFGA + RLS。
  - 放弃，原因是实现成本与调试成本过高。
- 全部使用硬编码 RBAC。
  - 放弃，原因是后续共享空间与细粒度权限难以扩展。
