# ADR-0001：采用 Kernel + Module + Adapter 分层

- 状态：Accepted
- 日期：2026-04-16

## 背景

世界树计划需要同时满足两个目标：

- 内核要稳定，能够长期维护记忆、任务、预算、审计等核心能力。
- 扩展能力要可插拔，未来新增多模态、训练、权限、整理等能力时不能把系统做成巨石服务。

如果没有明确分层，第一版快速实现的代码会在第二阶段演化成边界混乱的系统。

## 决策

采用三层结构：

- Kernel：稳定领域内核，负责节点、关联、版本、任务、预算、审计、权限基线、模块注册表、统一配置、核心事件。
- Module：领域能力模块，负责上下文修剪、Sub-Agent PR、多模态、自动整理、关系发现等增强能力。
- Adapter：外部依赖适配层，负责模型、OCR、ASR、对象存储、身份系统、消息系统等集成。

## 后果

正面影响：

- 可以约束未来能力增长的方式。
- 更适合做独立模块交付与替换。
- 更容易做契约测试与依赖分析。

负面影响：

- 第一阶段需要多做一层接口设计。
- 模块边界定义不清时，开发成本会先上升。

## 备选方案

- 单体服务直接加功能。
  - 放弃，原因是第二阶段能力会迅速污染核心流程。
- 全部做成微服务。
  - 放弃，原因是第一版复杂度过高，运维成本过重。
