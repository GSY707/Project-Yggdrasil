# Code Of Conduct

[中文版本](CODE_OF_CONDUCT.md)

Project Yggdrasil aims to keep a high-signal, low-noise open source environment where technical discussion stays rigorous and workable.

## Expected Behavior

- Focus on facts, code, tests, and verifiable conclusions.
- Respect contributors from different backgrounds, experience levels, and communication styles.
- Critique implementations, not people.
- Provide concrete evidence, reproduction steps, or alternatives when raising concerns.
- Stay open to correction when new evidence appears.

## Unacceptable Behavior

- personal attacks, harassment, discrimination, humiliation, or threats
- deliberate provocation, spam, repeated bad-faith argument loops, or discussion flooding
- exposing private information or private conversations without permission
- knowingly publishing material that leaks credentials, personal data, or sensitive security details
- using project channels for scams, unrelated promotion, or advertising

## Enforcement

Maintainers may take actions including:

- public warnings
- removing comments, issues, PRs, or discussions
- temporarily limiting interaction privileges
- permanently removing collaboration access

When enforcing, maintainers will prioritize community safety, discussion quality, and the available evidence.

## Reporting Conduct Problems

If a situation is not appropriate for public discussion, contact the repository maintainer `@GSY707` directly. If the report also involves a security risk, use the private flow described in `SECURITY.en.md` instead of exposing details in a public issue.

Maintainers will try to respond after establishing the facts, but will not promise endless debate over clearly out-of-bounds behavior.
